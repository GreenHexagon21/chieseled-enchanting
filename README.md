# Enchanting - Chieseled

This is a simple mod aimed to add late-game enchanting into the game trough minimal modification.

## Added Chiseled Bookshelf Mechanics

### The basics
- Chiseled bookshelves can be used for enchanting now. 
- If you have at least 3 enchanted books in a chiseled shelf it counts as a bookshelf, if you have 6 it counts as 2 regular bookshelves.
- Enchanting can go up to level 60 if you have 90 enchanted books around the table.

### How to get more enchantment previews
- If the sum of your enchanted book's levels goes above 135, you'll get to see another potential enchantment instead of just one. 
- For example if you have 45 Riptide III books on the chiseled shelves, you'll be able to see the extra preview.
- Remember it's possible only one preview shows, that means you got only got one enchantment on that tool, it's not a bug.

### How to get higher level enchants
- If you have all possible levels of an enchant stored on one shelve you can unlock an extra level of enchantment.
- For example Respiration I, Respiration II, Respiration III in the same shelf unlocks Respiration IV as a possible enchant
